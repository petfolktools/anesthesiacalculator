# Petfolk Veterinary Anesthesia & Drug Calculator

Interactive web application for canine and feline anesthetic drug calculations, fluid rates, breathing circuit sizing, and parameter monitoring.

🚀 **[Click here to open the Web App](https://<your-username>.github.io/anesthesia-calculator/)**

### Features
- Canine & Feline species toggles
- Automatic weight conversions (lbs/kg)
- Interactive drug selection & route assignment (IV/IM/SQ)
- Printable patient protocol sheet
